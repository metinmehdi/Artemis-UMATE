UMATE: telefonu qoşmaq

Bunu hər telefonda yalnız bir dəfə edin. Telefon və laptop eyni Wi-Fi şəbəkəsinə və ya hotspot-a qoşulmalıdır.

1. Sertifikatı yükləyin

Sertifikatı yüklə

iPhone

  1. Linki mütləq Safari-də açın və "Allow" (İcazə ver) düyməsinə basın.
  2. Settings → Profile Downloaded → Install.
  3. Settings → General → About → Certificate Trust Settings bölməsində "UMATE Local CA" seçimini açın.

Android

  1. Faylı yükləyin.
  2. Settings → Security → Encryption & credentials → Install a certificate → CA certificate yolu ilə yüklənmiş faylı seçin.
  3. Bu menyu tapılmasa, Settings-in axtarışına certificate yazın.

2. VR-ı açın

VR-ı aç

iPhone-da tam ekran üçün: Safari-də Paylaş → Ana ekrana əlavə et, sonra tətbiqi ana ekrandakı ikonla açın.

Sertifikatı quraşdırmaq alınmasa, xəbərdarlıq ekranında "Advanced → Proceed" (Android) və ya "Show details → visit this website" (iPhone) seçin.
